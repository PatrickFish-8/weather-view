# weather-view
User inputs location and Google's Imagen 3.0 generates a vibrant image of the location at the given moment.  
Uses accurate weather and location data, queried from various api endpoints.

This project utilized **NextJS** with **TypeScript** for **ReactJS** and **Tailwind CSS** on the frontend as well as **Spring Boot** for a functional backend.
